## Адаптивність і доступність

Перевірено viewport 1920×1080, 1440×1000 і 390×844. На широких екранах
переглянуто реєстр/конструктор, умови, preview, сесію й історію; на 390 px —
конструктор/умови, preview і issue dialog, списки, stored result, цінову чергу,
створення/перегляд сесії, sharing dialog і global menu. Виміряна ширина документа:
1905/1425/375 px при відповідному viewport (scrollbar), 390 px із модальним
overlay. Таблиці прокручуються всередині власних контейнерів.

Picker підтримує browse/type/select та Enter; текст пошуку сам по собі не змінює
значення. Перша Escape закриває його список, друга може закривати діалог через
наявну систему збереження/скасування. Браузер знайшов і допоміг усунути конфлікт
Escape у capture-handler загального діалогу. На 390 px речення умови переноситься
як характеристика, порівняння/значення, результат; нижні Apply/Cancel доступні.
Окремий технічний діалог не розтягує звичайний інспектор. Sharing dialog має
доступні поля й повертає фокус на «Поділитися» після Escape. Візуальні focus-ring
збережено; готовність позначена текстом/символом, не лише кольором.

**200% не підтверджено.** П’ять `Ctrl++` у вбудованому браузері не змінили
`innerWidth=1440` / `devicePixelRatio=1`; виконано `Ctrl+0`. CSS zoom чи
зменшення viewport не видавалися за справжній browser zoom.

У production cold-load не з’явилося нових помилок React. Журнал вкладки містив
старий HMR hook-order error від 10:01:09 UTC під час зміни набору hooks; повне
перезавантаження його усунуло. Це відокремлено від фінального production-load.
Навмисний запит неіснуючої сесії повертає очікуваний 404. Мережеві payload-и
не перехоплювалися через приховані API браузера: використано реальний UI,
спостережувані timestamps/результати й автоматичні серверні перевірки.

## Що ще потребує оператора

- Наявного безпечного другого облікового запису не було. Join/decline/accepted,
  revoke/leave/view-only/A→B→A не видаються за вручну пройдені. Серверні й
  rendered regressions цих контрактів зелені; користувачі/RBAC не створювалися.
- Справжній 200% zoom у звичайному браузері.
- Тривалий executing і безпечно перерваний generation не інсценувалися через
  production debug hooks. Використано established integration/race tests.
- Фінальне бізнес-приймання оператором, зокрема огляд залишених тестових назв.

Фінальний worktree: **48 змінених tracked + 4 нових файли, 0 staged**.
Зміни не staged, не committed і не pushed. Немає переходу на іншу гілку,
reset/clean/stash/merge/rebase. Детальний перелік файлів доступний у diff;
основні зміни — інспектор/condition/picker, export grid/review/controllers,
sessions/history/navigation, авторизований history read model, тести та ці docs.

Наступна окрема епіка після приймання — зіставлення локальних характеристик із
Magento attributes, порівняння options, явні авторизовані зміни, повторна
перевірка й майбутня історія імпорту. UX-5 не реалізує цю інтеграцію.
